# Presensi Praktikum

Sistem ini digunakan untuk absensi otomatis praktikum berdasarkan log **pretest** dari situs kuliah UAJY.  
Terdapat 3 mode aplikasi:
- GUI Desktop
- Web
- Flutter (Desktop/Mobile)

## Fitur Utama
- Membaca dan memproses log pretest untuk mencatat kehadiran otomatis.
- Menandai peserta yang hadir berdasarkan alamat IP.
- Ekspor hasil ke file Excel.

---

## Instalasi & Jalankan GUI (.exe)

1. **Clone repositori**
   ```bash
   git clone https://github.com/Kraids99/Presensi_Pretest.git
   ```

2. **Masuk ke direktori GUI**
    ```bash
    cd gui_app/dist
    ```

3. **Jalanin GUI (.exe)**
    ```bash
    start main.exe
    ```

## Instalasi & Jalankan Flutter (.exe)

1. **Clone repositori**
   ```bash
   git clone https://github.com/Kraids99/Presensi_Pretest.git
   ```

2. **Masuk ke direktori Flutter**
    ```bash
    cd flutter_app/flutter_file/build/windows/x64/runner/Release
    ```

3. **Jalankan Flutter (.exe)**
    ```bash
    start flutter_file.exe
    ```
